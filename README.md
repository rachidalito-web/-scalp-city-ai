# Scalp City AI — Mobile Edition

Mobiel geoptimaliseerde Streamlit webapp.

## Lokaal
`pip install -r requirements.txt`
`streamlit run app.py`

## Mobiel via internet
Deploy deze map op een Python/Streamlit hostingdienst. Na deployment krijg je een HTTPS-adres dat je in Chrome/Samsung Internet kunt openen en via 'Toevoegen aan startscherm' als app-icoon kunt bewaren.

Standaard: paper trading. Geen echte exchange-orders.
